# V6 UI / Runtime Fidelity Release

## Script Builder

V5의 상단 템플릿 중심 구조를 제거하고 다음 우선순위로 재설계했습니다.

1. 왼쪽: XML / 이미지 폴더 / 이미지 목록
2. 가운데 상단: 선택 이미지 + 생성 Lua (항상 표시)
3. 가운데 하단: 블록 편집 / 실행 흐름 / 이미지·기존 Action List 탭
4. 오른쪽: 템플릿 라이브러리

템플릿 라이브러리는 추천/전체/내 템플릿/커뮤니티, 검색, 카테고리, 즐겨찾기를 유지합니다. 기본 템플릿은 120개입니다.

## GUI Builder

기존 미리보기의 주요 오차 원인은 다음 두 가지였습니다.

- 360×320을 사용자 GUI 외곽 크기로 취급
- `w/h=-1` 자동폭을 `글자수 × 7px`로 계산한 뒤 CSS `min-width:max-content`가 실제 폭을 다시 늘림

V6에서는:

- 360×320을 X/Y 좌표 범위로 유지
- 실제 폼처럼 좌표 범위 바깥의 작은 클라이언트 여백을 별도로 렌더링
- 한글 자동폭을 Malgun Gothic 실제 측정값으로 계산
- Zoom 시 글꼴/체크/라디오/콤보 UI도 동일 비율 확대
- Drag/방향키는 컨트롤 크기가 아니라 X/Y 원점 범위 0~360 / 0~320 기준으로 제한
- 실제 폼 여백 안의 정상 컨트롤은 overflow 경고하지 않음

생성 Lua의 x/y/w/h 값은 임의 보정하지 않습니다.

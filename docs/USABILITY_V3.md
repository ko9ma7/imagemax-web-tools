# ImageMax Web Tools V3 — 실사용 UX 규격

## 1. 제품 원칙

이 서비스는 일반 Lua IDE가 아니다. ImageMax의 **이미지 리스트 / Action List / PreScript GUI** 구조를 초보자가 시각적으로 다룰 수 있게 하는 보조 도구다.

- XML을 프로젝트의 기준 데이터로 사용한다.
- 이미지별 `스크립트 입력`은 **호출 1회 후 즉시 반환**되는 액션 코드로 생성한다.
- `while true`, 무한 `repeat`, 장시간 자체 폴링은 기본 생성하지 않는다.
- ImageMax 기본 액션으로 해결 가능한 단순 클릭/딜레이/순서변경은 기본 액션을 우선 권장하고, Lua는 조건 조합/상태/카운트 등에 사용한다.

## 2. Script Builder 사용 흐름

1. ImageMax XML 불러오기
2. 필요하면 ImageMax 이미지 폴더 연결
3. 왼쪽 Image List에서 대상 이미지 선택
4. 가운데 `자주 쓰는 예문 / 템플릿` 선택
5. 필요한 값만 변경
6. 생성 Lua 확인 → 복사 또는 `.lua` 저장

### 초보자 우선 템플릿

- 현재 이미지 → 클릭
- 현재 이미지 → 키 입력
- 현재 이미지 → 이후 액션 건너뛰기
- 다른 이미지 발견 → 그 이미지 클릭
- 다른 이미지 없음 → 실패 액션
- 다른 이미지 발견 → 다음 N개 액션 패스
- 현재 이미지 N회 인식 후 실행
- 다른 이미지 최대 N회 **ImageMax 순회** 재확인
- GUI/전역 변수 조건 → 변수 값 지정
- N초 경과 후 실행 (Sleep 없이)
- 여러 이미지 중 발견된 후보 하나 랜덤 클릭
- 여러 후보 중 정확도가 가장 높은 이미지 선택
- 현재 화면 스크린샷 저장
- 로그 출력

### 이미지 폴더 연결

브라우저 보안상 웹페이지가 사용자의 로컬 ImageMax 폴더를 임의로 읽을 수 없다. 따라서 사용자가 `이미지 폴더 선택`을 눌러 폴더 접근을 한 번 허용해야 한다.

- XML 이미지명과 **파일명(확장자 제외)** 을 NFC 정규화 후 대소문자 무시로 연결한다.
- 하위 폴더 파일도 폴더 선택 결과에 포함된다.
- PNG / JPG / JPEG / GIF / WebP / BMP를 미리보기 대상으로 취급한다.
- `.grp` 항목은 단일 이미지가 아니므로 미리보기 대상에서 제외한다.
- 폴더 권한/File 객체는 브라우저 새로고침 후 보존하지 않는다. XML/스크립트 프로젝트는 저장할 수 있지만 이미지 폴더는 다시 선택해야 한다.
- 같은 파일명(확장자 제외)이 여러 하위 폴더에 존재하면 첫 번째 파일을 사용한다. 실사용 프로젝트에서는 이미지 이름을 고유하게 유지하는 것을 권장한다.

## 3. GUI Builder 사용 흐름

1. 기존 `PreScript.lua` 선택
2. 인코딩 `자동 판별` 사용 (문제가 있으면 CP949/EUC-KR 강제)
3. 탭/컨트롤 배치 복원 확인
4. 필요하면 XML 연결 → `EnableImage()` 등의 동작 대상 이미지를 목록에서 선택
5. 컨트롤 선택 → 속성 / 반환 ID / 값 변수 / 콜백 / 동작 규칙 편집
6. 검사 결과 확인 → `PreScript.lua` 저장

### 이번 버전의 Import 기준

실사용 PreScript에서 다음 형태를 해석한다.

- `gui1 = '탭이름'`
- `GUIAddTab(gui1)` / `GUISetCurTab(gui1)`
- `local x, y, w, h = ...`
- `local y = y + 27` 같은 좌표 누적
- `x + 80`, `y + 26` 등 단순 산술식
- `GUIAddText`, `GUIAddGroup`, `GUIAddButton`, `GUIAddCheck`, `GUIAddRadio`, `GUIAddCombo`, `GUIAddEdit`
- Dialog 및 Dialog child API
- `check_Cri1 = GUIAddCheck(...)` 같은 **컨트롤 반환 ID 변수**
- 콤보 항목 inline table (`{'A','B','C'}`)

해석하지 못한 동적/복잡 GUI 생성 구문은 버리지 않고 `미해석 GUI 구문` 경고로 표시하며, GUI 생성부 밖 기존 Lua는 `가져온 고급 Lua`로 보존한다.

## 4. GUI 규격 / 검사

- 사용자 탭 논리 좌표: 360 × 320
- 미리보기 배율: 100 / 125 / 150 / 200%
- `w=-1`, `h=-1`: 자동 크기
- Group은 시각적 그룹 박스이며 parent container로 생성하지 않는다.
- Dialog child만 `parent_id` 첫 번째 인수를 사용한다.
- Radio는 같은 그룹의 첫 번째 컨트롤에만 값 변수를 지정해야 한다.
- `GUIItemUpdate()`로 상태를 강제로 바꾸는 규칙은 필요한 경우 `GUIUpdate()`까지 생성한다.
- 실제 ImageMax에서 정상 사용되는 컨트롤이 경계를 1~몇 px 넘는 사례 때문에, 경계 검사는 8px 이하 오차를 허용하고 큰 초과만 경고한다.

## 5. 현재 안전 제한

- ImageMax XML 자체를 다시 저장/수정하는 기능은 아직 제공하지 않는다. XML 스키마 전체와 버전 호환성이 검증되기 전에는 원본 프로젝트 손상을 막기 위해 읽기 전용으로 사용한다.
- Script Builder의 랜덤/최고정확도 후보 템플릿은 한 액션 호출에서 과도한 검색을 막기 위해 최대 20개 후보를 권장/제한한다.
- 사용자 직접 Lua에는 고급 기능을 허용하되, 저장 전 대표적인 무한 반복 패턴을 검사한다.
- 로컬 폴더 파일은 서버로 업로드하지 않고 브라우저 메모리에서 미리보기한다.

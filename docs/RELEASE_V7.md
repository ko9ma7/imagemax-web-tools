# ImageMax Web Tools V7

## 핵심 수정
- GUI 미리보기는 컨트롤별 배율 계산을 제거하고 1:1 논리 좌표로 렌더한 뒤 **폼 전체를 한 번만 확대**합니다.
- 타이틀바/탭/컨트롤이 동일한 배율로 확대되어 폰트 폭과 좌표 rounding 누적 오차를 줄였습니다.
- GroupBox는 ImageMax/Windows에서 보이는 외곽 여백을 미리보기에서만 보정하며, 생성 Lua의 w/h 값은 변경하지 않습니다.
- PreScript import 시 그리드를 기본으로 끄고 자동 화면맞춤합니다.
- Script Builder의 템플릿 카드가 flex 축소로 태그 한 줄만 보이던 문제를 수정했습니다. 카드가 고정 높이로 축소되지 않고 제목/설명/적용 버튼을 항상 표시합니다.
- 최종 Lua 영역을 최소 320px로 유지해 템플릿보다 생성 코드가 우선 보이도록 했습니다.

# ImageMax Web Tools — Template Library (120 presets)

## 설계 원칙

이 라이브러리는 일반 Lua 프로그램용 예제가 아니라 **ImageMax 이미지 리스트의 `스크립트 입력` 액션에서 1회 호출되는 로직**을 빠르게 구성하기 위한 프리셋입니다. 무한 루프 대신 ImageMax의 다음 리스트 순회와 전역 상태 변수를 이용합니다.

## 전체 구성

| 카테고리 | 수 | 주요 용도 |
|---|---:|---|
| 기본 | 19 | 현재 이미지 처리, 클릭/키/상태 전환/초기화 |
| 이미지 연계 | 26 | 다른 이미지 발견·미발견, MultiImage, 후보 선택, 재확인 |
| 상태/횟수 | 27 | N회 호출, 비차단 시간, 1회 실행, 쿨타임, 변수 조건 |
| 액션 흐름 | 13 | PassAct/PassAllAct/GotoFailAct/GotoImage/OpenScript/Stop |
| 입력/좌표 | 11 | 마우스 좌표·드래그·키보드·클립보드 입력 |
| 알림/기록 | 13 | 스크린샷·로그·사운드·Telegram/Discord/KakaoTalk |
| 데이터/환경 | 11 | Clipboard/INI/Pixel/FindWindow/대상 창 크기 |

## 사용 화면

- **추천**: 가장 자주 쓰는 템플릿만 노출합니다.
- **전체**: 120개 템플릿을 검색/카테고리로 찾습니다.
- **즐겨찾기**: 별표한 템플릿만 즉시 필터링합니다.
- **내 템플릿**: 현재 블록 구성을 이름/설명/카테고리/작성자와 함께 저장합니다.
- **커뮤니티**: 승인되어 `community/index.json`에 등록된 템플릿을 불러옵니다.

- **현재 이미지 → 클릭** **[추천]** — 현재 리스트 이미지가 이미 인식된 상태에서 다시 검색하지 않고 바로 클릭합니다.
- **현재 이미지 → 클릭 후 짧은 대기** **[추천]** — 현재 이미지를 클릭한 뒤 지정한 밀리초만큼만 짧게 대기합니다.
- **현재 이미지 → Space** **[추천]** — 현재 이미지가 인식되면 Space 키를 1회 입력합니다.
- **현재 이미지 → Enter** — 현재 이미지가 인식되면 Enter 키를 1회 입력합니다.
- **현재 이미지 → ESC** — 현재 이미지가 인식되면 ESC 키를 1회 입력합니다.
- **현재 이미지 → 변수 값 지정** **[추천]** — 현재 이미지 호출 시 전역 변수 값을 지정합니다.
- **현재 이미지 → 변수 +1** — 카운터나 진행 상태 변수에 1을 더합니다.
- **현재 이미지 → 0/1 토글** — 전역 변수 값을 0과 1 사이에서 전환합니다.
- **현재 이미지 → 자기 자신 비활성화** — 현재 이미지가 한 번 처리된 뒤 다시 인식되지 않도록 비활성화합니다.
- **현재 이미지 → 다른 이미지 활성화** — 현재 이미지가 인식되면 다음 단계에서 사용할 다른 이미지를 활성화합니다.
- **현재 이미지 → 로그 출력** — 현재 이미지 액션이 실행됐다는 메시지를 로그창에 남깁니다.
- **현재 이미지 → 스크린샷 저장** — 현재 대상 창 전체를 한 번 저장합니다.
- **현재 이미지 → 클릭 → 자기 비활성화** — 클릭 후 현재 이미지를 비활성화하여 같은 단계가 다시 실행되는 것을 막습니다.
- **현재 이미지 → 클릭 → 다음 이미지로 이동** — 현재 이미지를 처리한 뒤 지정 이미지부터 인식 흐름을 이어갑니다.
- **현재 이미지 → 클릭 → 남은 액션 패스** — 클릭을 완료한 뒤 현재 이미지의 뒤쪽 액션을 모두 건너뜁니다.
- **현재 이미지 → 상태 저장 → 다음 이미지 이동** — 진행 상태 변수를 먼저 기록한 뒤 GotoImage로 다음 단계로 이동합니다.
- **현재 이미지 → 스크린샷 + 로그** — 현재 화면을 저장하고 로그도 함께 남겨 문제 상황 추적에 사용합니다.
- **현재 이미지 → 결과 변수 2개 초기화** — 새 구간 시작 전에 자주 쓰는 결과/횟수 변수를 0으로 초기화합니다.
- **현재 이미지 → 다음 이미지 활성화 + 자기 비활성화** **[추천]** — 단계 전환 시 다음 이미지를 켜고 현재 이미지는 끄는 대표적인 상태 전환 패턴입니다.

### 이미지 연계 · 26개

- **다른 이미지 발견 → 그 이미지 클릭** **[추천]** — 선택한 다른 이미지를 이번 호출에서 한 번 검색하고 발견하면 클릭합니다.
- **다른 이미지 발견 → 키 입력** — 다른 이미지를 한 번 확인하고 발견된 경우 키 입력을 실행합니다.
- **다른 이미지 발견 → 변수 지정** — 다른 이미지가 보이는 경우 결과/상태 변수를 변경합니다.
- **다른 이미지 발견 → 이미지 활성화** — 확인 이미지가 발견되면 지정 이미지를 활성화합니다.
- **다른 이미지 발견 → 이미지 비활성화** — 확인 이미지가 발견되면 지정 이미지를 비활성화합니다.
- **다른 이미지 발견 → 인식 순서 이동** — 다른 이미지가 발견되면 GotoImage로 다음 인식 위치를 바꿉니다.
- **다른 이미지 발견 → 다음 N개 액션 건너뛰기** — 발견되면 PassAct로 현재 이미지의 뒤쪽 액션 일부를 건너뜁니다.
- **다른 이미지 발견 → 이후 액션 모두 건너뛰기** — 발견되면 PassAllAct로 현재 이미지의 남은 액션을 실행하지 않습니다.
- **다른 이미지 없음 → 실패 액션** **[추천]** — 다른 이미지를 1회 확인하고 없으면 GotoFailAct로 이동합니다.
- **다른 이미지 없음 → 지정 이미지로 이동** — 확인 이미지가 없을 때 다음 인식 순서를 지정 이미지로 변경합니다.
- **다른 이미지 없음 → 변수 지정** — 확인 이미지가 없을 때 실패/대기 상태 변수를 지정합니다.
- **이미지 활성 상태면 실행** — 특정 이미지가 현재 활성화되어 있는지 확인하고 행동합니다.
- **이미지 비활성 상태면 실행** — 특정 이미지가 비활성 상태인지 확인하고 행동합니다.
- **이미지 A + B 모두 만족** — MultiImage의 AND 조건으로 여러 이미지 조합을 1회 확인합니다.
- **이미지 A / B 중 하나 만족** — MultiImage의 OR 조건으로 후보 중 하나가 보이는지 확인합니다.
- **여러 이미지 중 발견된 것 하나 랜덤 클릭** — 선택한 이미지 목록을 각각 한 번 확인하고 발견된 후보 중 하나를 랜덤 클릭합니다.
- **여러 후보 중 정확도 가장 높은 이미지 클릭** — 같은 영역에서 후보들을 한 번씩 확인하고 가장 높은 정확도의 결과 하나를 클릭합니다.
- **다른 이미지 최대 N회 순회 재확인 후 클릭** **[추천]** — 한 호출당 ImageSearch 1회만 수행하고 못 찾으면 다음 ImageMax 순회에서 다시 확인합니다.
- **다른 이미지 발견 → 클릭 → 현재 이미지 비활성화** — 확인 대상이 보이면 그 이미지를 클릭하고 현재 리스트 이미지는 비활성화합니다.
- **다른 이미지 발견 → 클릭 → 남은 액션 패스** — 다른 이미지를 처리한 경우 현재 이미지의 나머지 액션을 실행하지 않습니다.
- **다른 이미지 발견 → 스크린샷** — 특정 화면이나 결과 이미지가 보였을 때 한 번만 현재 화면을 저장합니다.
- **다른 이미지 발견 → 0/1 상태 토글** — 확인 이미지가 발견될 때마다 지정 상태 변수를 0/1로 바꿉니다.
- **다른 이미지 발견 → 키 입력 → 남은 액션 패스** — 확인 이미지가 보이면 키 입력만 수행하고 현재 액션 흐름을 종료합니다.
- **다른 이미지 없음 → 남은 액션 패스** — 보조 이미지가 없을 때 현재 이미지의 뒤쪽 액션을 전부 건너뜁니다.
- **다른 이미지 없음 → 복구 스크립트 열기** — 필수 화면이 없으면 다른 ImageMax 스크립트로 전환해 복구 루트를 시작합니다.
- **다른 이미지 발견 → 상태 저장 → 순서 이동** — 다른 이미지 확인 결과를 변수로 기록하고 지정 이미지부터 다음 인식을 시작합니다.

### 상태/횟수 · 27개

- **현재 이미지 N회 호출 후 클릭** **[추천]** — 스크립트가 호출될 때마다 카운트하고 N번째 호출에서만 현재 이미지를 클릭합니다.
- **현재 이미지 N회 호출 후 키 입력** — N번째 호출에서만 지정 키를 입력하고 카운터를 초기화합니다.
- **현재 이미지 N회 호출 후 변수 지정** — N번째 호출에서 결과 변수를 변경합니다.
- **현재 이미지 N회 호출 후 스크린샷** — N번째 호출에서만 스크린샷을 저장합니다.
- **현재 이미지 N회 호출 후 남은 액션 패스** — N번째 호출부터 현재 이미지의 뒤쪽 액션을 건너뜁니다.
- **N초 경과 후 현재 이미지 클릭** **[추천]** — 첫 호출 시간을 기억하고 이후 순회에서 경과시간이 N초 이상일 때 클릭합니다.
- **N초 경과 후 변수 지정** — Sleep으로 멈추지 않고 순회가 계속되는 동안 시간 조건을 확인합니다.
- **N초 경과 후 다른 스크립트 열기** — 일정 시간이 지나면 지정 ImageMax 스크립트로 전환합니다.
- **현재 실행 구간에서 딱 1회만 클릭** — 전역 플래그를 이용하여 최초 한 번만 행동하고 이후 호출은 바로 반환합니다.
- **딱 1회만 변수 초기화** — 초기화가 중복 실행되지 않도록 최초 호출에서만 변수 값을 지정합니다.
- **클릭 후 N초 쿨타임** **[추천]** — 마지막 실행 시각을 기억하여 N초가 지나기 전에는 클릭하지 않습니다.
- **키 입력 후 N초 쿨타임** — 지정 키 입력을 일정 시간 간격으로만 허용합니다.
- **변수 값이 같으면 실행** **[추천]** — GUI 체크박스/콤보/전역 변수 값을 비교해 행동합니다.
- **변수 값이 다르면 실행** — 전역 변수의 값이 지정값과 다를 때 행동합니다.
- **변수가 기준값 이상이면 실행** — 횟수·페이지·점수 같은 숫자형 변수를 비교합니다.
- **변수가 기준값보다 작으면 실행** — 숫자형 상태값이 기준보다 작은 동안만 행동합니다.
- **다른 이미지 N회 재확인 실패 → 실패 액션** — 다른 이미지를 순회당 1회 확인하고 최대 횟수에 도달하면 실패 액션으로 이동합니다.
- **다른 이미지 N회 재확인 실패 → 지정 이미지 이동** — 최대 재확인 횟수에 도달하면 GotoImage를 호출합니다.
- **현재 이미지 N회 호출 후 자기 비활성화** — 같은 이미지가 N번 처리된 뒤 해당 이미지를 더 이상 인식하지 않도록 끕니다.
- **현재 이미지 N회 호출 후 지정 이미지 이동** — N번째 호출에서만 GotoImage를 실행해 다음 단계로 전환합니다.
- **현재 이미지 N회 호출 후 다른 스크립트 열기** — 반복적으로 같은 상황이 발생할 때 N회째에 복구/재실행 스크립트로 전환합니다.
- **N초 경과 후 스크린샷** — 대기 상태가 일정 시간 이상 유지될 때 현재 화면을 저장합니다.
- **N초 경과 후 실패 액션** — Sleep 없이 시간을 확인하다 제한시간을 넘으면 GotoFailAct를 호출합니다.
- **N초 경과 후 남은 액션 패스** — 지정 시간이 지난 상태에서는 현재 이미지의 나머지 액션을 건너뜁니다.
- **최초 1회만 다른 이미지 활성화** — 한 구간에서 처음 들어왔을 때만 다음 단계 이미지를 활성화합니다.
- **최초 1회만 로그 출력** — 같은 이미지가 여러 번 호출돼도 첫 진입 메시지는 한 번만 출력합니다.
- **스크린샷 저장 N초 쿨타임** — 같은 화면의 스크린샷이 과도하게 쌓이지 않도록 일정 간격으로만 저장합니다.

### 액션 흐름 · 13개

- **현재 이미지 → 이후 액션 모두 건너뛰기** **[추천]** — 현재 이미지의 남은 액션을 실행하지 않고 다음 ImageMax 흐름으로 넘어갑니다.
- **현재 이미지 → 다음 N개 액션 건너뛰기** — PassAct의 개수를 지정해 일부 액션만 건너뜁니다.
- **현재 이미지 → 실패 액션으로 이동** — 현재 액션 뒤의 인식 실패 액션으로 이동합니다.
- **현재 이미지 → 지정 이미지로 인식 순서 이동** — GotoImage로 다음 인식 순서를 지정합니다.
- **현재 이미지 → 다른 ImageMax 스크립트 열기** — 현재 프로젝트 흐름에서 다른 ImageMax 스크립트로 전환합니다.
- **현재 이미지 → ImageMax Stop** — 현재 조건에서 자동화를 중지합니다.
- **ImageMax Stop 상태 확인** — IsStop 상태를 확인하여 정리용 코드를 실행합니다.
- **ImageMax Pause 상태 확인** — IsPause 상태에서 수행할 코드를 구성합니다.
- **현재 이미지 비활성화 → 다음 이미지 이동** — 현재 단계 종료와 다음 단계 이동을 한 번에 처리합니다.
- **다른 이미지 활성화 → 그 이미지로 이동** — 다음 단계 이미지를 먼저 활성화한 다음 바로 해당 인식 위치로 이동합니다.

### 데이터/환경 · 11개

- **클립보드 내용이 같으면 실행** — 현재 클립보드 문자열을 비교한 뒤 행동합니다.
- **INI 설정값이 같으면 실행** — IniGetValue로 설정파일 값을 읽어 조건에 사용합니다.
- **픽셀 RGB가 같으면 실행** — 대상 창 기준 좌표의 RGB 값을 읽어 정확히 일치할 때 행동합니다.
- **특정 윈도우가 있으면 실행** — FindWindow로 클래스명/창 이름을 확인합니다.
- **특정 윈도우가 없으면 실행** — FindWindow 결과가 없을 때 재실행 스크립트 등을 호출할 수 있습니다.
- **대상 창 너비 조건** — GetTargetWindowPos의 너비를 비교합니다.
- **대상 창 높이 조건** — GetTargetWindowPos의 높이를 비교합니다.
- **클립보드 내용이 다르면 실행** — 클립보드 문자열이 원하는 값과 다를 때 복구/입력 동작을 실행합니다.
- **INI 설정값이 다르면 실행** — 현재 INI 설정이 기준값과 다를 때 상태 변수를 설정합니다.
- **픽셀 RGB 일치 → 클릭 / 불일치 → 실패** — 한 픽셀의 RGB를 비교해 맞으면 현재 이미지를 클릭하고 아니면 실패 액션으로 이동합니다.
- **윈도우 발견 → 로그 / 없음 → 복구 스크립트** — 대상 창 존재 여부에 따라 정상/복구 루트를 명확히 나눕니다.

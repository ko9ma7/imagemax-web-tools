공유 템플릿 제출

Script Builder에서 만든 .imxtpl.json 또는 템플릿 팩을 올리면 먼저 브라우저에서 형식을 검사합니다.

파일을 선택하면 이름·규칙 수·크기를 검사합니다.

어떻게 등록되나요?

  1. 페이지에서 JSON 형식·크기·필수 필드 검사
  2. 기본 모드: GitHub Issue 제출 화면 자동 생성
  3. Issue가 등록되면 GitHub Action 실행
  4. Action이 다시 서버측 검증 후 커뮤니티 파일/색인 생성
  5. 자동 PR 생성 → 관리자 검토 후 Merge
  6. Merge 후 GitHub Pages의 공유 템플릿에 노출

직접 업로드 모드

현재는 GitHub Issue 기반 안전 모드입니다. 서버리스 중계기를 설정하면 GitHub 로그인 화면 없이 페이지에서 제출까지 끝낼 수 있습니다.
